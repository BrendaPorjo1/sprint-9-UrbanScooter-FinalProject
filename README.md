# Urban Scooter – Final QA Project

This repository contains the test case spreadsheet for the **Urban Scooter** final project, developed during **Sprint 9**.  
The project includes test design and execution for the **Web Application**, **Mobile App**, and **Backend API** of the Urban Scooter system.

---

## 📋 Project Overview

The goal of this project was to design, execute, and document test cases for different components of the Urban Scooter platform.  
All test cases were created and executed according to the provided requirements and specifications.

The spreadsheet includes:
- Positive and negative test cases
- Test results and execution status
- Links to reported bugs in Jira

---

## 🧠 Tasks Summary

### **Task 1: Urban Scooter Web Application**
- Designed test cases for the **“About Customer”** form (“Who the scooter is for”) on the **Place Order** screen.
- Validated input fields such as **Customer Name** and **Phone Number**.
- Executed tests on **Google Chrome (v85+)** and **Opera (v71+)** with a resolution of **1280x720**.
- Recorded bugs found during testing and linked them in Jira.

### **Task 2: Urban Scooter Mobile App**
- Installed and configured the **Urban Scooter Android app** using **Android Studio (API 31)**.
- Created a **courier account** via the API using POST requests in JSON format.
- Designed and executed test cases for features highlighted in yellow in the requirements.
- Verified layout and design consistency based on Figma references.
- Documented test results and linked Jira bug reports.

### **Task 3: Urban Scooter Backend**
- Reviewed backend requirements and API documentation.
- Designed test cases for **Add Courier** and **Delete Courier** functionalities.
- Executed tests and logged bugs found during API validation.
